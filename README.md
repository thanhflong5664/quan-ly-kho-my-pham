

# CSDL quản lý nhân viên và kho đóng hàng mỹ phẩm
Bài tập lớn học phần Cơ sở dữ liệu (INT1313) – Nhóm 14 – PTIT

## Cách chạy
1. Chạy `TABLE.sql` rồi `INSERT.sql` trong MySQL Workbench.
2. Chạy các file `TRUYVAN1.sql` … `TRUYVAN6.sql` để xem kết quả 6 truy vấn.
3. Chương trình giao diện: mở `KhoMyPhamGUI.java` trong project Maven (có thư viện `mysql-connector-j`), sửa `PASS` thành mật khẩu MySQL của bạn rồi chạy.
